# Category: INSTALL_CANCELLED

## Error Signature
- User cancelled installation

## Common Causes
- Deliberate user action
- Unexpected popup interrupted wizard
- UAC prompt dismissed

## Recommended Actions
- Restart installation
- Complete all wizard steps without cancelling
- Dismiss any UAC prompts with Yes/Allow

## Confidence Scoring
- High: Explicit "User cancelled" message in logs
- Medium: Installation stopped mid-wizard with no error code
