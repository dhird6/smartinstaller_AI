# Error: Missing ollama.exe

## Symptoms
- ollama.exe not found
- Installation appears successful but executable missing

## Root Causes
- Antivirus quarantine
- Corrupted installer
- Incomplete installation

## Diagnosis
- Check Windows Security → Protection History
- Search entire disk for ollama.exe
- Verify installer checksum

## Resolution
- Restore from quarantine
- Reinstall as Administrator
- Disable real-time protection temporarily
