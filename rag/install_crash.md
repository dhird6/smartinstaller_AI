# Category: INSTALL_CRASH

## Error Signature
- Crash report detected
- Installer process terminated unexpectedly

## Common Causes
- Corrupt installer file
- Missing dependencies or runtimes
- OS compatibility issue
- Insufficient memory

## Recommended Actions
- Re-download installer (verify checksum)
- Run as Administrator
- Verify OS version compatibility
- Install required runtimes (e.g. .NET, MSVC)

## Confidence Scoring
- High: Crash report or exception dump detected
- Medium: Installer process exited with non-zero code and no output
